# Code of Conduct

We want this project to be a respectful, practical collaboration space. Participants must communicate in good faith, focus on technical evidence, respect privacy and security boundaries, and avoid harassment, discrimination, personal attacks, or publishing another person's private information.

Project maintainers may edit, remove, or reject contributions and discussions that violate these expectations. To report a conduct concern privately, contact the maintainer through the GitHub profile. Reports will be handled as confidentially as practical.
